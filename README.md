## Featured Project

### Luxury Perfume

A fragrance e-commerce application with a Django REST Framework backend. I designed the system architecture, database structure, and business workflows, and developed the project end-to-end.

The backend separates writes into services and reads into selectors. Checkout updates the cart and reserves inventory in one transaction, with PostgreSQL constraints protecting data integrity. Pytest covers backend workflows, and GitHub Actions supports CI/CD.
